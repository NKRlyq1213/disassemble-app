拆料 / 板材排版工具（Streamlit + 模組化 Python）
========================================
本專案是一個以 Streamlit 製作的輕量化板材拆料 / 排版（nesting / cutting plan）輔助工具。
你只需要輸入零件尺寸與數量、板材尺寸與庫存片數，以及切割限制（kerf 切割縫間距與外框留邊 margin），
程式會使用 rectpack（啟發式 2D bin packing）計算排版結果，並輸出 placements（座標）與視覺化排版圖（可匯出 SVG）。

----------------------------------------------------------------------
功能（FEATURES）
----------------------------------------------------------------------
- 零件表格輸入：尺寸（W/H）、數量、是否允許旋轉
- 板材設定：板材寬/高、板材片數（0 = 不限）
- Kerf（切割縫）：零件之間的最小間距
- Margin（留邊）：板材外框保留邊界
- 計算需要的板材片數與利用率
- Placements（座標輸出）：零件座標 + 尺寸 + 是否旋轉
- 視覺化：排版圖 + 匯出 SVG
- 匯出檔案：
  - placements.csv
  - result.json
  - sheet_*.svg

----------------------------------------------------------------------
最佳化（Optimization / Heuristics）
----------------------------------------------------------------------
- B1 Best-of：多次試驗（不同排序策略，並可選擇嘗試多種 rectpack 演算法）挑選最佳結果
- B2 Repair：
  - 填入未排入零件（best-fit insertion）
  - 減少最後一張板材（嘗試把最後一張的零件搬到前面板材）
  - 刪除任意板材（嘗試將某張板材的零件搬到其他板材，若成功則移除該板材）
  - Compact（壓緊）：在同一張板材內讓零件更緊密排列（tighten）

----------------------------------------------------------------------
視覺化便利性（Visualization Convenience）
----------------------------------------------------------------------
- 合併相同排列：若多張板材排出相同版型，可合併成一個「Pattern」顯示。

----------------------------------------------------------------------
使用說明（Usage Guide / UI）
----------------------------------------------------------------------
1. 選擇單位：mm 或 cm
2. 設定板材 W/H，並可設定 sheet_qty（0 = 不限）
3. 設定 kerf 與 margin
4. 設定求解器選項：
   - B1 best-of：試驗次數 / 時間上限 / seed / 是否嘗試多種演算法
   - B2 repair：填未排入 / 減少最後一張 / 刪除任意板材
5. 在表格編輯零件後按下「Compute / 計算」
6. 檢視：
   - 指標：使用片數、利用率、未排入數量
   - placements 座標表（coordinates）
   - 排版圖（逐張或合併相同排列）
7. 下載 CSV / JSON / SVG

----------------------------------------------------------------------
演算法與注意事項（Algorithms & Notes）
----------------------------------------------------------------------
單位（Units）
- 內部計算一律使用 mm
- UI 可切換 mm/cm（會自動換算縮放）

Kerf 與 Margin
- kerf：零件之間的間距（以矩形有效 padding 的方式處理）
- margin：板材外框留邊；零件必須放在 sheet - 2*margin 的可用區域內

旋轉限制（Rotation constraint）
- rotate=True：允許旋轉
- rotate=False：在 rectpack 下屬於「事後檢查」的軟約束（先排再檢查是否被旋轉）
  若需要嚴格的旋轉硬約束，可考慮後續加入 OR-Tools 求解器（future work）
